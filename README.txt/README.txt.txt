IT Help Desk / Ticketing System
Project Code: CPP62
Enrollment No.: IU2541230537

1. Project Description
   This project is a C++ based IT Help Desk / Ticketing System designed to manage users, support tickets, technicians, and ticket resolutions.

2. Features

* Add, display, search, update and delete tickets
* Add and manage users
* Add and manage technicians
* Add and manage resolutions
* Process support tickets
* Generate reports
* Save and load data using text files
* Input validation and exception handling
* Data persistence after closing and reopening the program

3. Technologies Used

* Programming Language: C++
* IDE: Visual Studio Code
* Compiler: MinGW / g++
* Data Storage: Text files (.txt)
* Diagrams: diagrams.net (draw.io)

4. How to Run

5. Open the Source folder in the project directory.

6. Compile the project using the required g++ command.

7. Run the generated executable.

8. Use the menu options to manage users, tickets, technicians and resolutions.

9. Data Storage
   The program stores data in the Data folder:

* users.txt
* tickets.txt
* technicians.txt
* resolutions.txt

The data is saved when using the Save Data option and is loaded when the program starts.

6. Project Structure
- Source/      : C++ source and header files
- Data/        : Text files used for data storage
- Diagrams/    : UML diagrams
- Executable/  : Project executable
- Screenshots/ : Program screenshots
- README.txt   : Project documentation
- ProjectReport.pdf : Final project report

7. Project Requirements
- C++ compiler such as MinGW / g++
- Visual Studio Code or any compatible C++ IDE
- Windows operating system

8. Project Status
The project has been tested for adding, displaying, searching, updating and deleting records. Ticket processing, report generation, saving and loading data, validation, exception handling and data persistence have also been tested successfully.
